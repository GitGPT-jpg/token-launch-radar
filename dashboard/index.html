Which protocol without a token would be worth the most?

A board of pre-token protocols, ranked by an implied value derived from the snapshot itself — no names hardcoded, no price predicted. Every row carries a farm plan: what to do, what it costs, how long it takes.

How the value is worked out — the model, in full

Implied value = TVL × category multiple × growth × maturity.

  1. Category multiple. For each category, the median FDV/TVL of the protocols in that category that already have a token (at least 4 of them; thinner categories use the global median). The multiple is clamped to 0.05 – 3.00.
  2. Growth. The protocol's 7-day TVL change, clamped to −50% – +100%, times a 0.40 weight: growth = 1 + growth% / 100 × 0.40.
  3. Maturity. Age since the protocol was first listed, up to 730 days: maturity = 0.70 + min(age, 730) / 730 × 0.30. A protocol with no listing date counts as 365 days old.
